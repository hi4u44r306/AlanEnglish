# 按鈕陰影與找功能的操作審核

2026-10-09；基準 `8515929`，分支 `codex/student-visual-calm`。已由 PR #506 發布，正式登入與實機待驗。

本次在 Edge 操作實際 MainNavbar、StudentNavbar、MaterialsNavigator 與學生首頁，提供離線學生、老師、管理員資料。選單開關、分類、連結、React Router 導航與 Escape 都是真實元件行為；到達其他頁面後只呈現路徑標記，不載入正式後端或驗證目的頁業務流程。家長視角採學生帳號查看設定／週報入口，沒有另建家長權限模型。

## 發現與修正

| 使用者任務 | 原先問題 | 本機調整／操作結果 |
| --- | --- | --- |
| 找作業、週報 | 桌面藏在「我的角色」，手機先展示四個角色／獎勵入口 | 桌面選單改名「我的學習」，兩端把學習紀錄放最前；開選單→選功能共兩次點擊 |
| 更換角色／修改暱稱 | 目的頁叫「我的設定」，選單叫「我的角色」 | 選單目的地統一「我的設定」；手機底部「我的」或桌面帳號仍一次到達 |
| 老師／管理員改班級教材 | 手機管理區在主要功能及教材清單後，教材設定未完整出現在第一屏 | 「管理」改名「班級與學生」；手機管理區放在主要功能與教材之前，班級教材設定完整出現在第一屏 |
| 開 Workbook | 分類與冊別需要分開選 | 選單→Workbook→第 1 冊三次到達；首頁教材架則一次到達，沒有新增重複常駐入口 |
| 首頁按鈕、頭貼設定 | 桌面四個導覽鍵、次要操作和頭貼選擇仍有陰影 | 移除導覽／次要／頭貼按鈕陰影，底部導航保留淡分隔陰影，公開 CTA 大模糊陰影改為 2px；主遊戲／任務操作維持輕微立體感 |

保留遊戲插圖、彩色圖示與選取／錄音／禁用狀態。彈窗與抽屜的陰影用於區分前後層，焦點提示用於鍵盤操作，兩者不視為一般按鈕裝飾而全面刪除。共用下拉選單項目最低高度由 42px 提至 44px。

## 證據

- 學生在 320／412／768／1440px；老師、管理員各在 412／1440／1600px。調整前後各 42 組導覽檢查涵蓋六個學生目的地、Workbook 分類、選單關閉／Escape與班級教材目的地。沒有 pageerror 或遠端網路請求。
- 同資料首頁在 1440px 有陰影的可見操作由 5→1，768px 由 3→1；320／412px 維持只突出主任務一個。這是當前示範狀態，不是全站所有按鈕的數量。
- 另 12 組一鍵操作：四種寬度的首頁主任務、教材架及設定捷徑，皆到達對應路徑。互動對照頁切換管理員並點班級教材也通過。
- MainNavbar 既有 35 項測試通過，包含權限、通知、教材及客戶端導航。局部 JSX ESLint 與五份修改 SCSS 的編譯通過；九組代表畫面 × 六種寬度共 54 組版面檢查、設定鍵盤與三組短螢幕口說檢查通過。
- 本機互動對照：`output/student-navigation-preview/review.html`。證據：`navigation-before.json`、`navigation-after.json`、`one-click-journeys.json` 與前後 PNG；測試：`output/student-navigation-tests.log`。

預覽樣式排序修正為只將精確的 Navigation.scss 放在共用頁面樣式之前，避免將 StudentAdventureNavigation.scss 因同名結尾而排錯；此為忽略輸出的驗證工具修正，不是應用執行邏輯變更。

## 還需要真實使用者確認的部分

所有角色完整目的頁、長教材分類／大量通知、不同資格、正式登入與 iPhone Safari 尚未驗證。學生進階功能仍在分組選單內；管理員「系統」有十項工具，這是來源檢視，沒有逐項操作正式資料。可使用上述互動預覽試找功能，但不應將這次操作視為完整網站可用性研究或正式資料流程已通過。
