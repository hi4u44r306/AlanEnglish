## 公開前建議確認

1. 請律師或消保專線 1950 確認退費條款，特別是是否適用教育部「網際網路教學服務定型化契約應記載及不得記載事項」。草稿已採按剩餘天數比例退費的保守寫法。
2. 向綠界確認個人會員可販售的商品類別與額度。
3. 隱私權政策中的第三方服務清單，需與實際使用的服務一致（目前依專案現況列出）。
4. 價格拆分（習作本 NT$500＋平台使用費）是為了計算退費，擁有者可調整，但四份文件要一起改。
5. 會員服務條款第十二條的管轄法院暫填「臺灣桃園地方法院」，是依現有線索的推測，請改成經營者實際所在地的法院。
6. 隱私權政策中「口說錄音保留一段時間」需填入實際保存天數；各項安全與保存描述公開前要與系統現況逐項核對。
