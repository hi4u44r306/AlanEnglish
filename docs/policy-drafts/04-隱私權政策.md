# 隱私權政策（草稿，未公開）

生效日期：【生效日期】

Alan English（以下稱「本平台」）由【經營者名稱】經營。本平台的使用者主要是兒童，我們只收集提供學習服務所需要的資料，並依個人資料保護法處理。

## 一、我們收集哪些資料

| 資料 | 內容 | 用途 |
|---|---|---|
| 帳號資料 | 學生姓名或稱呼、登入帳號、生日、家長 Email | 建立帳號、身分確認、寄送通知與每週報告 |
| 學習資料 | 聆聽紀錄、口說作答與分數、作業完成情形、等級與獎勵點數 | 顯示進度、產生報告、判定過關與獎勵 |
| 口說錄音 | 口說大挑戰時錄下的聲音 | 評分與讓學生回聽自己的錄音 |
| 訂購資料 | 訂購人姓名、聯絡電話、收件地址或取貨門市、訂單內容 | 出貨、退換貨、客服 |
| 付款資料 | 付款結果與交易編號 | 確認付款與對帳。**信用卡號等付款資訊由金流公司處理，我們不會取得或保存** |
| 社交資料 | 學生自訂的暱稱、頭像、好友關係 | 好友與排行榜功能 |
| 技術資料 | 裝置與瀏覽器類型、登入時間、錯誤紀錄 | 維持服務安全與排除問題 |

我們不會要求孩子提供身分證字號、學校名稱、住家地址或照片。

## 二、兒童資料與家長同意

1. 未滿 18 歲的使用者須由家長同意後才能使用本平台。
2. 家長可以隨時聯絡我們，查看、更正或要求刪除孩子的資料。
3. 排行榜與好友功能只顯示學生自訂的暱稱與頭像，不顯示真實姓名、Email、生日或班級。
4. 好友搜尋只接受完整的暱稱或好友碼，沒有公開的學生名單。

## 三、口說錄音怎麼處理

1. 句子朗讀等題型在學生自己的裝置上評分，錄音不會因評分而離開裝置。
2. 字母與拼字等題型，錄音會傳送到語音評分服務（Microsoft Azure）取得分數。
3. 為了讓學生回聽，錄音可能保存在我們的儲存空間一段時間，之後會刪除。
4. 我們不會把錄音用於廣告，也不會公開。

## 四、我們怎麼使用資料

- 提供、維護與改進學習功能
- 產生學習紀錄與家長每週報告
- 處理訂單、出貨、退款與客服
- 寄送與帳號或方案有關的通知（例如使用期限即將到期）
- 防止作弊、濫用與維護系統安全
- 依法律規定配合主管機關

我們不會販售使用者資料，也不會把兒童資料用於個人化廣告。

## 五、協助我們提供服務的第三方

為了提供服務，資料會交由下列服務處理，處理地點可能在臺灣以外：

| 服務 | 用途 |
|---|---|
| Google Firebase | 帳號登入驗證 |
| Supabase | 資料庫與後端 |
| Cloudflare | 網站主機與教材音檔儲存 |
| Microsoft Azure | 部分口說題型的語音評分 |
| OpenAI | AI 教材生成（僅限有此功能的方案） |
| Google Cloud | 示範語音 |
| Resend | 寄送 Email |
| 綠界科技 | 付款與物流（開始線上販售後） |

我們只提供完成該項用途所需的資料。

## 六、資料保存多久

| 資料 | 保存期間 |
|---|---|
| 帳號與學習資料 | 帳號存續期間。方案到期或離開英文班後仍會保留，方便之後繼續使用 |
| 口說錄音 | 僅保留一段時間供回聽，之後刪除 |
| 訂購與付款紀錄 | 依稅務與會計法規要求的年限 |
| 帳號刪除後 | 除法律要求保存的紀錄外，於合理期間內刪除或去識別化 |

## 七、您的權利

依個人資料保護法，您（或家長代理孩子）可以向我們要求：

1. 查詢或閱覽資料
2. 取得資料複本
3. 補充或更正資料
4. 停止收集、處理或利用
5. 刪除資料與帳號

請透過下方聯絡方式提出。為了保護帳號安全，我們會先確認您的身分（例如以註冊的家長 Email 聯絡）。我們會在收到請求後 30 天內處理。

## 八、資料安全

- 資料傳輸使用加密連線。
- 密碼不以明文保存。
- 教材音檔與錄音存放在不公開的儲存空間。
- 只有必要的人員可以存取資料，並有存取紀錄。

沒有任何系統能保證絕對安全。如果發生影響您資料的安全事件，我們會依法通知。

## 九、Cookie 與類似技術

本平台使用必要的 Cookie 與瀏覽器儲存空間來維持登入狀態與記住設定。我們不在學生使用的頁面放置第三方廣告追蹤。

## 十、政策修改

本政策有修改時會在網站公告並註明生效日期。對資料使用方式有重大變更時，會另外以 Email 或站內通知告知家長。
