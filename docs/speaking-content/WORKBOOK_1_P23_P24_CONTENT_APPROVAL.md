## 4. 發布前人工檢查

1. 管理員確認 J-R、S-Z 的字母順序、主詞單複數、be 動詞、否定句及介系詞與原頁一致。
2. P23 的皇冠圖片是否以 `king`、白袍人物是否以 `nurse`，必須由教材負責人明確核准，不以圖片推測直接發布。
3. P24 的第 25 題必須核准 `yaks` 複數；第 26 題雖語意特殊，若保留教材原句不得擅自改成不同答案。
4. 每題圖片須由管理員從合法來源上傳到私人 R2，完成 MIME、檔案簽章、尺寸與 R2 HEAD 驗證。
5. 所有可見 token 的一次性示範音檔均為 `ready` 後才能發布；學生不得觸發付費生成。
6. 學生端只收到挖空句型、短效圖片網址及可見 token 音檔，不收到完整答案、accepted responses 或私人 object key。
7. 任一題用詞、圖片、權利或音檔未核准時，整個題組維持 `draft`。

## 5. E2E 驗收

- P23／P24 各自洗牌且每題只出現一次，完成最後一題才通關。
- 只念空格單字不得通過；完整句及核准的完整替代說法才可完成。
- 明確錯誤的單複數、be 動詞、否定句或主詞不得誤判正確。
- 學生循序解鎖；老師與管理員可預覽所有已發布關卡，但不寫學生進度或獎勵。
- 手機、iPad、桌面、鍵盤、螢幕閱讀器、麥克風允許／拒絕與 safe area 均通過。
