# AI 教材：台灣國小課綱對齊與 PDF 題庫規劃

## 目的

AI 教材生成必須同時做到：

1. 對齊台灣國小英語文課綱。
2. 清楚區分官方課綱要求與 Alan English 為避免難度漂移而設定的產品限制。
3. 未來可依 Alan English 自有 PDF 教材的冊別、單元與頁碼出題。
4. 不複製或重製未取得授權的出版社教材內容。

## 官方依據

- 國家教育研究院「十二年國民基本教育課程綱要－語文領域（英語文）」：
  https://www.naer.edu.tw/PageSyllabus?fid=177
- 國家教育研究院「教科書審定資訊網」：
  https://textbooks.naer.edu.tw/openbook.aspx

目前程式中的正式課綱對應：

| Alan English 程度 | 課綱定位 | 核心能力 |
|---|---|---|
| 國小低年級 | 一至二年級英語前導，不宣稱為全國部定英語階段 | 字母、自然發音前導、招呼、生活高頻字、短句聽說 |
| 國小中年級 | 第二學習階段，三至四年級 | 字母與自然發音、教室用語、生活用語、簡易句型、直接理解 |
| 國小高年級 | 第三學習階段，五至六年級 | 日常對話、簡易短文、標示、故事排序、一次簡易推論 |
| 國中基礎 | 七年級銜接 | 鞏固國小字詞與句型後進入較完整的對話與短文 |

全國部定英語課程自三年級開始。三至四年級每週一節，五至六年級每週兩節。國小畢業累積目標為口語應用至少 300 個字詞，並能拼寫其中至少 180 個字詞。

## 官方內容轉成出題規則

### 低年級：英語前導

- 題材：自己、家人、教室、數字、顏色、形狀、身體、動物、食物、玩具、天氣與感受。
- 形式：聽音辨字、字圖配對、單句理解、直接問答。
- 文字：短語與極短句為主，題目指示可使用繁體中文。
- 禁止：長篇閱讀、推論、音標、過去式、未來式及複雜文法。

### 中年級：第二學習階段

- 題材：家庭、朋友、學校生活、日常作息、服飾、住家、天氣、時間、興趣與主要節慶。
- 能力：26 個字母、子音母音組合、自然發音、教室與日常生活用語、簡易句型。
- 題型：字詞辨識、句型判斷、直接細節、生活對話與字詞分類。
- 禁止：完成式、被動語態、關係子句、複雜比較及推論陷阱。

### 高年級：第三學習階段

- 題材：朋友與人際、健康、運動、購物與價格、日期月份、交通、旅行、自然環境、文化節慶、科技與學習習慣。
- 體裁：生活對話、校園標示、菜單、地圖、時刻表、通知、歌謠、韻文及簡短故事。
- 能力：理解對話或短文主旨、介紹自己與家人、故事排序、整合明確資訊作簡易猜測。
- 題型：直接細節、主旨、對話目的、故事排序與最多一題單步推論。
- 禁止：現在完成式、複雜被動語態、關係子句、多層從屬子句及國中以上學術字彙。

## Alan English 產品限制

課綱沒有為每一份 AI 文章規定固定句長、文章字數或每次新字數，因此程式另外設定保守上限。這些上限屬於 Alan English 的生成品質規則，不得對外宣稱為教育部數字。

目前限制定義在：

- `supabase/functions/_shared/ai-material-quality.ts`

Edge Function 會把所選級別的完整規格放入提示詞。若使用者自訂需求與級別衝突，級別限制優先。

## PDF 教材題庫：建議架構

PDF 不應該被當成「重新訓練模型」。正確做法是建立可追溯的教材資料庫，生成時只取指定冊別與單元的內容。

### 第一版：指定教材與單元，不需要向量搜尋

1. 管理員上傳自有或已授權 PDF 到私有 Storage bucket。
2. 系統判斷 PDF 是文字版或掃描版。
3. 文字版直接擷取；掃描版進行 OCR。
4. 依冊別、單元、課次及頁碼切分內容。
5. 管理員檢查並修正擷取結果。
6. 出題頁選擇「教材 → 單元 → 頁碼範圍」。
7. Edge Function 只將該範圍的內容交給 AI，並要求答案完全依據教材。
8. 每份生成教材保存來源文件、單元與頁碼，日後可追查。

這一版成本低、結果最可控，也最適合目前教材數量。

### 第二版：自動找相關教材

教材量增加後，再為分段內容建立 embeddings，使用 Supabase pgvector 依主題搜尋相關段落。檢索仍需同時套用：

- 教材 ID
- 程度
- 冊別
- 單元
- 版本
- 啟用狀態

不應只依向量相似度跨教材任意取文。

## 安全與品質要求

- Storage bucket 必須是 private。
- 上傳、擷取、校對與停用教材只允許 admin/teacher 的明確權限。
- Service Role Key 只可出現在伺服器端 Edge Function。
- PDF 檔案類型、大小、頁數與雜湊必須驗證。
- OCR 文字未經管理員確認前不得用於正式學生題庫。
- AI 必須只引用選定來源，不知道時要拒絕猜測。
- 題目需保存來源頁碼，但不可向未擁有該教材權限的學生洩漏整頁內容。
- 第三方課本、習作或題庫沒有授權時，不得上傳、重製或拿來產生高度相似內容。

## 實作順序

1. 完成本 PR 的台灣國小課綱難度規則與答案位置平衡。
2. 使用低、中、高年級各生成至少 10 份教材人工驗收。
3. 收集過難字彙、錯誤句型與模糊選項，建立品質回歸案例。
4. 選一份 Alan English 自有 PDF 做擷取試驗。
5. 建立私有文件、單元、分段與來源引用資料表。
6. 建立管理員 PDF 上傳與校對頁面。
7. 讓 AI 教材生成支援指定教材／單元／頁碼。
8. 教材量變大後才加入 embeddings 與自動檢索。
