## 實作結果

- 帳號與教師作業有獨立的登入範圍記憶體快取，30 秒內避免重讀、合併同時請求，5 分鐘後離開再返回重新讀取。仍停留本頁時保留舊清單並重新核對，避免長時間編輯時突然消失。重新整理瀏覽器會重新讀取後台，不將學生清單、搜尋、憑證或登入卡寫入 localStorage。
- 服務端確認成功的帳號、會員、學生建立／刪除／登入卡操作才使清單失效；舊的延遲回應不能覆蓋確認過的修改。401／403／404 移除對應資料，UID／角色與權限範圍各自隔離，登出清除。
- 斷線及一般服務失敗保留清單並顯示重新讀取，單一口說題組也能重試。登入、資格、鎖定與未發布教材各有適合的返回入口，不把網路問題誤導成購買會員。
- 帳號每頁 25 筆，搜尋與班級等篩選改變回第一頁；返回恢復搜尋、班級、頁碼與捲動位置。帳號編輯、晉級測驗及會員各工作區的草稿，有變更才提示；取消切頁、關閉、上一頁／下一頁或登出保留草稿。
- `GuardedBrowserRouter` 沿用目前 React Router 的同版 history adapter，在 POP 發布新位置前決定是否離開；避免取消後只恢復網址但已卸載表單。既有 Route、ProtectedRoute、AuthProvider 與資格設定不變。清爽藍色及既有兒童學習外觀保留。
